The reviewed source inventory found no retired named import or removed-path consumer requiring a cosmetic rewrite. Source compatibility does not prove final packed resolution or behavior. ## Confirmed independent-stage fixes

SPA's Vitest environment requires jsdom. A standalone install/test failed because the dependency existed only at the workspace root; SPA now declares the same jsdom range itself. Each standalone stage owns its dependency/build ignore rules, preventing copied-stage lint/format commands from traversing installed dependencies or generated output.

API/SSR uses Monaco and now owns the same DOMPurify 3.4.16 override as the root. An independent install previously lost the root override and failed its production audit. The root lock also takes compatible source-map-js and http-cache-semantics patches without changing application/platform ranges.

API-only's explicit Node types setting was inspected and its ordinary standalone typecheck passed using the installed dependency graph. It is not reported as a reproduced missing-type defect.

## Qualification boundary

`npm run acceptance` exercises the installed graph. The historical `npm run test:stages -- --baseline ...` mode requires a separate source revision with published 0.4 declarations and deliberately rejects this 0.5 source. See [the runner instructions](../scripts/qualification/README.md) for exact commands and evidence. The known Vite+ alias development peer metadata diagnostic is retained separately from passing application gates; other peer problems fail the runner.

Final candidate mode rejects 0.4 declarations and requires the frozen versions and archive SRIs of all 18 reviewed packages. Before closing the release migration, replay independent six-stage installs/checks/builds/runtime fixtures and root browser acceptance against that exact graph, then qualify installed-CLI-created starters, Website and Destroyer separately. No publication is authorized by these checks.

The provider browser matrix remains blocked by the fixture's redirect transport:
Playwright routes only the first request of a redirect chain, so a real 303 can
escape the canonical-endpoint forwarding handler. A bounded fresh-GET experiment
also raced navigation and is excluded from this source. See the
[provider qualification boundary](../provider-auth/README.md#browser-qualification-currently-blocked).
The six earlier stages' independent gates do not establish provider browser or
hosted platform acceptance.
